# 人物分析方法参考

## 人物弧光 (Character Arc)

### 定义
- 人物在故事过程中发生的内在变化
- 从开始到结束，人物的信念、价值观、或行为方式发生改变
- 优秀的故事 = 外在情节 + 内在弧光

### 人物弧光的类型

**1. 正向弧光 (Positive Arc)**
- 人物从缺陷走向完整
- 克服内在阴影
- 例子：《星球大战》卢克从农场男孩到绝地武士

**2. 负向弧光 (Negative Arc / Tragedy)**
- 人物固守缺陷，导致毁灭
- 拒绝改变，或改变方向错误
- 例子：《教父》迈克尔逐渐失去人性

**3. 平弧 (Flat Arc)**
- 人物的核心信念不变，但影响周围世界
- 人物是"真理的承载者"
- 例子：《福尔摩斯》福尔摩斯的逻辑从未改变

### 人物弧光的结构

**开始状态 (Starting Point)**
- 人物的缺陷或误解（Lie）
- 人物的真实需求 vs 表面欲望
- 人物的保护壳（盔甲）

**激励事件后的变化**
- 人物被迫面对缺陷
- 尝试用旧方式解决问题（失败）

**中点/转折点**
- 人物开始意识到缺陷
- 尝试改变，但还不彻底

**一无所有时刻**
- 缺陷导致最大失败
- 必须面对真相（Truth）

**结局状态 (Ending Point)**
- 人物克服了缺陷（或屈服于它）
- 展现新的行为方式
- 证明弧光完成

## 人物关系分析

### 关系类型

**1. 盟友关系 (Ally Relationships)**
- 帮助主人公实现目标
- 可能是导师、伙伴、或爱情兴趣
- 功能：提供技能、情感支持、喜剧 relief

**2. 对手关系 (Opponent/Antagonist Relationships)**
- 阻止主人公实现目标
- 不一定是"坏人"，只是有不同目标
- 功能：创造冲突、考验主人公、代表反面价值观

**3. 爱情关系 (Romantic Relationships)**
- 通常是B故事的核心
- 帮助主人公学习主题
- 功能：展示主人公的柔软面、提供情感 stakes

**4. 导师-学生关系 (Mentor-Student Relationships)**
- 传递智慧或技能
- 通常在中点前"毕业"（导师死亡或离开）
- 功能：为最终对抗做准备

**5. 家庭关系 (Family Relationships)**
- 展示主人公的过去和根源
- 可能是动力或障碍
- 功能：提供情感深度、解释人物动机

### 关系动态分析

**关系弧光 (Relationship Arc)**
- 关系如何随时间变化
- 从冲突到理解，或从信任到背叛
- 例子：《星战》汉·索罗和卢克从竞争对手到兄弟

**关系网络 (Relationship Web)**
- 所有人物如何相互连接
- 每个人物至少与两个其他人有关联
- 避免"孤岛式"人物（只与主人公有关系）

**关系冲突 (Relationship Conflict)**
- 人物目标不一致导致的冲突
- 可能是内在冲突（如爱情 vs 责任）
- 功能：增加故事的复杂性

## 人物动线分析

### 物理动线 (Physical Journey)
- 人物在物理空间中的移动
- 与心理旅程平行
- 例子：《指环王》佛罗多从夏尔到末日火山

### 心理动线 (Psychological Journey)
- 人物内在的变化过程
- 与人物弧光相同
- 通常用视觉隐喻来表现

### 情感动线 (Emotional Journey)
- 人物情感状态的变化
- 可以用情感曲线图来表现
- 例子：从恐惧 → 愤怒 → 接受 → 爱

### 关系动线 (Relational Journey)
- 人物如何与他人建立、断开、重建关系
- 通常与主线情节交织
- 例子：《复仇者联盟》从各自为战到团队合作

## 人物维度

### 立体人物的三个维度 (Robert McKee)

**第一维：人物塑造 (Dimension 1: Characterization)**
- 表面特征：年龄、性别、职业、外貌
- 可观察的行为和习惯
- 这是"人物面具"

**第二维：人物真相 (Dimension 2: True Character)**
- 在压力之下做出的选择
- 人物的核心价值观
- "人物真相在人处于压力之下选择去做什么时得到揭示"

**第三维：人物弧光 (Dimension 3: Character Arc)**
- 人物是否发生变化
- 变化的方向和性质
- 静态人物 vs 动态人物

### 人物的矛盾性
- 优秀人物是矛盾的集合体
- 矛盾创造深度和真实感
- 例子：勇敢但恐惧、善良但自私

## 分析方法

### 分析人物弧光
1. 人物的Lie（误解）是什么？
2. 人物的Truth（真相）是什么？
3. 什么事件让人物开始怀疑Lie？
4. 什么事件迫使人物面对Truth？
5. 结局时，人物是否接受了Truth？

### 分析人物关系
1. 画人物关系图（可以用Mermaid语法）
2. 识别每对关系的性质（盟友/对手/爱情/家庭）
3. 关系如何随时间变化？
4. 关系如何推动情节？

### 分析人物动线
1. 人物的物理旅程是什么？
2. 人物的心理旅程是什么？
3. 画出情感曲线（X轴=时间，Y轴=情感强度）
4. 关键转折点在哪里？

### 输出格式
生成的分析报告应包括：
1. **人物档案** - 每个主要人物的详细分析
2. **人物关系图** - 用图表展示关系网络
3. **人物弧光图** - 展示人物如何变化
4. **情感曲线图** - 展示情感旅程
5. **学习要点** - 从分析中学习编剧技巧

## 工具建议

### 可视化工具
- **Mermaid图表** - 用于人物关系图、弧光图
- **表格** - 用于对比人物特征
- **时间线** - 用于展示人物动线

### 输出格式
- Markdown格式，易于阅读和分享
- 包含图表和可视化
- 结构清晰，便于学习
