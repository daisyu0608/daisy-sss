# 《故事》理论参考 - Robert McKee

## 核心概念

### 故事结构层级
1. **事件 (Event)** - 最小单位，改变人物生活价值的状态
2. **场景 (Scene)** - 在某一相对连续的时空中，通过冲突表现出来的一段动作
3. **序列 (Sequence)** - 一系列场景，构成一个完整的小故事弧光
4. **幕 (Act)** - 一系列序列，以高潮时刻为单位
5. **故事 (Story)** - 完整的叙事结构

### 故事三角
- **大情节 (Master Plot)** - 经典设计，因果关系的强驱动
- **小情节 (Mini Plot)** - 最小主义设计，较少因果关系
- **反情节 (Anti Plot)** - 非因果关系的实验性叙事

## 结构分析要点

### 幕的结构
1. **第一幕（设置幕）** - 建立人物、背景、激励事件
2. **第二幕（对抗幕）** - 核心冲突展开，人物面对各种障碍
3. **第三幕（结局幕）** - 高潮和结局，故事问题得到解答

### 激励事件 (Inciting Incident)
- 打破主人公生活平衡的事件
- 必须在故事早期发生（通常在前10-15%）
- 引发主人公的欲望和目标

### 故事价值 (Story Values)
- 正面/负面价值的转换（如：正义/非正义、自由/奴役）
- 每个场景都应该有价值转换
- 故事的总体弧光是价值的根深转变

### 人物塑造 vs 人物真相
- **人物塑造** - 表面的特征（职业、外貌、习惯）
- **人物真相** - 深层的选择和价值观
- 在压力之下，人物真相才会显现

## 场景分析

### 优秀场景的要素
1. **冲突** - 至少两股力量对抗
2. **转折** - 场景结果不可预测
3. **价值转换** - 从正面到负面或反之
4. **情感变化** - 人物情感状态改变

### 场景类型
- **主动场景** - 主人公采取行动追求欲望
- **被动场景** - 反应场景，情感处理

## 对白原理
- 对白不是信息传输，而是 **潜文本 (Subtext)**
- 人物说一套，意味着另一套
- 优秀的对白有 **冰山理论** - 只说表面的1/10

## 故事危机、高潮、结局
- **危机** - 故事最大压力点，必须做出不可逆的选择
- **高潮** - 故事最强烈的情感时刻
- **结局** - 所有线索收束，价值状态确定

## 分析方法
分析剧本时，需要识别：
1. 激励事件是什么？发生在哪里？
2. 故事价值是什么？如何转换？
3. 幕的转折点在哪里？
4. 人物弧光如何展现？
5. 场景是否有冲突和转折？
6. 对白的潜文本是什么？
