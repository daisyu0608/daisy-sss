# 细致场景分析框架 - Detailed Scene Analysis

## 核心概念

### 当提供完整剧本时的分析方法
- **逐场景分析**：不只是概括，而是深度分析每个关键场景
- **文本细读**：分析对白、动作描述、潜文本
- **表格精细化**：多个维度评估每个场景

### 表格字段解释

**基础信息**：
- **场景#** - 场景编号
- **页码** - 在剧本中的页码范围
- **场景名** - 给场景起一个描述性名称
- **地点** - 场景发生地点
- **时间** - 一天中的时间或日期
- **人物** - 场景中出现的全部人物

**分析维度**：
- **场景类型** - 主动/被动/揭示/过渡
- **功能** - 这个场景在故事中做什么（设置、转折、高潮等）
- **主角目标** - 主人公在这个场景想要什么
- **冲突类型** - 内在/人际/社会/自然/机械/超自然
- **对手** - 谁或什么阻止主人公实现目标

**价值分析**：
- **价值开始** - 场景开始时的价值状态（正面/负面）
- **价值结束** - 场景结束时的价值状态
- **价值转换** - 是否有转换？如何转换？
- **转折点** - 场景中的转折是什么？

**质量评估**：
- **潜文本评分** - 1-10分，对白是否有潜文本？
- **节奏评分** - 1-10分，场景节奏是否有效？
- **晚进早出** - 是否遵循晚进早出原则？

**总结**：
- **优点** - 这个场景的优点
- **问题** - 这个场景的问题
- **备注** - 其他观察

## 使用流程

### 当用户提供剧本文件时：

**步骤1：读取并理解剧本**
- 完整读取剧本
- 识别所有场景（通常每个场景标题是一个新场景）
- 列出场景列表

**步骤2：逐场景分析**
- 对每个场景，填写"完整场景分析表"
- 对关键场景，填写"对白分析表"
- 追踪人物关系和主题发展

**步骤3：生成多维度表格**
- 序列分析表
- 节拍表（如果使用《救猫咪》）
- 英雄之旅阶段表（如果使用英雄之旅）
- 人物动线追踪表
- 主题发展追踪表

**步骤4：生成可视化**
- 人物关系图（基于追踪表）
- 情感曲线图（基于场景分析）
- 结构图表（基于序列/节拍分析）

**步骤5：撰写详细分析报告**
- 每个表格都有详细解释
- 不只给表格，还要分析"为什么"
- 提供具体改进建议

## 输出示例

### 场景分析示例输出：

```markdown
## 场景3：餐厅对话（p.8-12）

### 基础信息
- **地点**：餐厅
- **时间**：晚上7点
- **人物**：小明、小红
- **场景类型**：被动场景

### 功能分析
- **情节功能**：展示小明的内心矛盾
- **人物功能**：揭示小明的恐惧（亲密关系）
- **主题功能**：探讨"勇气"主题

### 冲突分析
- **冲突类型**：内在冲突（小明 vs. 自己）
- **对抗力量**：小明的恐惧 vs.  desire
- **冲突强度**：7/10

### 价值转换分析
- **开始价值**：希望（正面）
- **结束价值**：绝望（负面）
- **转换是否合理**：✅ 合理，因为小红提到前男友

### 对白分析（精选）

| 人物 | 对白 | 潜文本 | 评分 |
|------|------|--------|------|
| 小明 | "你最近好吗？" | 我想你，但不敢说 | 9/10 |
| 小红 | "挺好的，你呢？" | 我注意到你紧张，为什么？ | 8/10 |

### 节奏分析
- **场景长度**：4页
- **是否合适**：❌ 太长，应该2-3页
- **晚进早出**：❌ 没有遵循，前1页是闲聊

### 优点
1. 对白有潜文本
2. 人物内心冲突真实
3. 情感共鸣强

### 问题
1. 场景太长（4页→应该2-3页）
2. 没有遵循晚进早出（前1页可以删掉）
3. 价值转换不够强烈（应该更绝望）

### 改进建议
1. **删减前1页**：从"你最近好吗？"之前开始
2. **提前结束**：在小红说"我累了，先走一步"后立刻结束
3. **加强价值转换**：让小红提到"我现在有男朋友了"（更绝望）
```

## 学习要点

1. **细致分析 > 粗略概括** - 每个场景都值得深度分析
2. **表格是工具，不是目的** - 表格之后的分析更重要
3. **追踪动线** - 人物、关系、主题都要追踪变化
4. **具体建议** - 不只说"不好"，要说"为什么"和"怎么改"
5. **基于文本** - 所有分析都要引用剧本原文
