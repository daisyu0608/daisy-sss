# Script Up · 剧本分析工具

> Script Up - 提升你的剧本写作。一款专业剧本分析工具，整合9大经典编剧理论体系，以学习为导向，助力编剧成长。

## 📖 简介

**Script Up** 是一款整合9大经典编剧理论体系的专业分析工具。它不对作品进行评判，而是帮助编剧、电影学生和教育者从经典剧本中学习创作技巧。

### 核心理念
- 🎓 **学习导向** - 分析是为了理解，而非评判
- 🔍 **精细入微** - 16字段逐场景分析
- 📊 **可视化** - Mermaid图表直观展示
- 🎭 **多元理论** - 9大框架全面解析

## ✨ 功能特色

### 9大理论框架
1. **Robert McKee《故事》理论** - 结构层次、价值转换、人物维度
2. **Blake Snyder《救猫咪》** - 15个节拍点、10种故事类型
3. **三幕剧结构** - 经典三段式分析
4. **Joseph Campbell英雄之旅** - 12阶段、人物原型
5. **序列法** - 8-12序列专业分解 ⭐
6. **场景构建** - 晚进早出、冲突类型、潜文本 ⭐
7. **人物分析** - 人物弧光、关系网络、动线追踪
8. **类型片惯例** - 动作、爱情、惊悚等8大类型 ⭐
9. **主题与潜文本** - 主题识别、"展示不要告诉" ⭐

### 精细化分析表格
- **完整场景分析表**（16字段）- 场景功能、冲突、价值转换等
- **对白分析表**（潜文本分析）- 字面意思 vs. 潜文本
- **人物动线追踪表** - 关系变化、情感曲线
- **主题发展追踪表** - 主题随剧情发展

### 可视化输出
- 📈 三幕结构图表
- 🎬 序列分解甘特图
- 👥 人物关系网络图
- 📊 人物弧光图
- 💓 情感曲线图
- 🗺️ 英雄之旅地图
- 🎯 主题追踪图表

## 🚀 使用方法

### 安装
1. 下载 `script-writing-analysis.zip`
2. 在 WorkBuddy 中进入 Skill 管理页面
3. 点击"安装 Skill"，上传 zip 文件
4. 安装完成后即可使用

### 示例交互

**分析剧本：**
```
用户：请分析《教父》的剧本结构
AI：加载相关理论框架，提供多维度分析，生成人物关系图和弧光图
```

**学习理论：**
```
用户：为初学者解释《救猫咪》节拍表
AI：加载参考文档，提供教育性解释和知名电影示例
```

**逐场景分析：**
```
用户：逐场景分析我的剧本
AI：生成16字段精细化表格，追踪人物动线、情感曲线、主题发展
```

## 📝 分析原则

本技能遵循以下原则：

1. **学习而非评判** - 分析是为了理解大师技巧，而非班门弄斧式地评价
2. **尊重版权** - 不复制大段剧本内容，聚焦结构分析
3. **多元视角** - 运用多种理论框架，全面解析
4. **可视化优先** - 用图表和表格让复杂概念易于理解
5. **教育价值** - 每次分析都要提取可学习的要点

## 📚 理论基础

本技能整合了以下经典编剧理论著作：

- Robert McKee - *《故事》* (Story)
- Blake Snyder - *《救猫咪》* (Save the Cat)
- Joseph Campbell - *《英雄之旅》* (The Hero's Journey)
- Syd Field - *《电影剧本写作基础》* (Screenplay)
- Linda Seger - *《创造人物弧光》* (Creating Unforgettable Characters)
- Christopher Vogler - *《作家之旅》* (The Writer's Journey)
